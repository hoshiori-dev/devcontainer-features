# GitHub Platform Settings

Read this before changing anything on the remote repository, when a merge is blocked for a reason no check explains, or
when a setting below changes. Remote settings are maintainer actions: agents read them back, never change them
(`.agents/knowledge/agent-authority.md`).

Repository: `hoshiori-dev/devcontainer-features` · owner: organization · visibility: public · plan: unknown (not
readable by API) · enforcement tier: rulesets available (public repository). The default agent token gets 403 on branch
protection, Actions permissions, and organization issue types, so those rows are verified in the UI.
